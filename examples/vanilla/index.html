Cubit UI

Vanilla Web Components 기반 디자인 시스템. Shadow DOM 캡슐화, CSS Custom Properties 토큰, 라이트/다크 자동 대응, WCAG 2.1 AA 포커스 표준. React · Svelte 패키지가 동일 API를 재사용합니다.

Components 25 React · Svelte 지원 WCAG 2.1 AA Light / Dark TypeScript 100%
컴포넌트 둘러보기 테마 전환

Button <ui-button>

variant(primary/secondary/outline/danger) × size(sm/md/lg). 비동기 작업 중에는 disabled와 busy 라벨로 잠그는 것이 표준 패턴입니다.

Primary Secondary Outline Danger Disabled 
<ui-button variant="primary">Primary</ui-button>
<ui-button variant="danger" disabled>Danger</ui-button>
Small Medium Large

PROPS

Badge <ui-badge>

상태 표시용 캡슐 배지. 실시간 상태에는 variant가 상태에 맞춰 "값"으로 바뀌어야 합니다(고정 표시 금지).

NEW SECONDARY Active Pending Failed Outline 
<ui-badge variant="success">Active</ui-badge>

PROPS

Avatar <ui-avatar>

이미지가 없으면 이름 이니셜로 자동 대체합니다. 원형이 기본, shape="square" 로 사각 지원.

<ui-avatar name="홍 길동" size="lg"></ui-avatar>
<ui-avatar src="/profile.png" size="md"></ui-avatar>

PROPS

Card <ui-card>

header · body · footer 3단 슬롯. bordered로 테두리 강조.

Cubit Card

본문 영역. 카드 내부에서도 토큰이 그대로 적용됩니다.

확인
테두리 없는 카드

variant 속성으로 배경 톤을 조정할 수 있습니다.

 
<ui-card bordered>
  <div slot="header">제목</div>
  본문
  <div slot="footer">액션</div>
</ui-card>

PROPS

Table <ui-table>

semantic thead/tbody를 슬롯합니다. 파서 제약 때문에 <template>으로 구조를 보존하면 어떤 환경에서도 안전합니다.

<ui-table striped bordered hoverable>
  <template><thead>…</thead><tbody>…</tbody></template>
</ui-table>

PROPS

Input <ui-input>

포커스 링은 --ui-color-focus-ring 토큰으로 통일되어 있습니다. Enter 전송은 컨테이너에서 keydown으로 처리하세요.

확인
<ui-input placeholder="이메일 입력" aria-label="이메일"></ui-input>

PROPS

Select <ui-select>

옵션은 <ui-option value> 자식으로 정의합니다.

사원과장이사

  <ui-option value="staff">사원</ui-option>
</ui-select>

Checkbox · Radio · Switch

checked/disabled/indeterminate 상태. 같은 name 라디오는 단일 선택.

<ui-switch checked>알림 수신</ui-switch>

공통 PROPS

Alert <ui-alert>

정적 안내용. 행동 결과 피드백은 Alert가 아닌 Toast를 사용하세요.

토큰 변경 없이 라이트/다크가 자동 전환됩니다. 변경 사항이 저장되었습니다. 작성 중인 내용이 사라질 수 있습니다. 요청이 실패했습니다. 네트워크 상태를 확인하세요. 
<ui-alert variant="error" title="오류" closable>요청 실패…</ui-alert>

PROPS

Progress <ui-progress>

0~max 값으로 표기. aria-label로 진행 내용을 설명합니다.

<ui-progress value="60" variant="success" aria-label="검사"></ui-progress>

PROPS

Skeleton <ui-skeleton>

콘텐츠 로딩 Placeholder. shimmer는 prefers-reduced-motion에서 정지됩니다.

<ui-skeleton lines="3"></ui-skeleton>
<ui-skeleton variant="circle"></ui-skeleton>

PROPS

Spinner <ui-spinner>

버튼/검색 등 즉시 피드백용 회전 인디케이터.

<ui-spinner size="md"></ui-spinner>

PROPS

Toast <ui-toast>

행동 결과 피드백. 우하단 스택 컨테이너에 담아 쌓습니다. 자동 소멸 + aria-live.

정보 성공 에러 
// 스택 컨테이너에 동적 생성 → open으로 표시
const t = document.createElement('ui-toast');
t.setAttribute('variant', 'success');
stack.appendChild(t); t.open = true;

PROPS

Modal <ui-modal>

포커스 트랩 + ESC 탈출 + 백드롭 닫기. 확인 결과는 토스트로 피드백하는 것이 표준입니다.

모달 열기 
<ui-modal title="테스트 모달">…</ui-modal>

PROPS

Drawer <ui-drawer>

오프캔버스 사이드 패널. 이 문서의 모바일 목차도 이 컴포넌트입니다.

왼쪽 Drawer 
<ui-drawer side="right" title="정보">…</ui-drawer>

PROPS

Dropdown <ui-dropdown>

slot="trigger"로 트리거를 지정하고 ui-dropdown-item을 메뉴로 쌓습니다.

메뉴 ▾ 수정 복제 삭제 
<ui-dropdown>
  <ui-button slot="trigger">메뉴 ▾</ui-button>
  <ui-dropdown-item value="edit">수정</ui-dropdown-item>
</ui-dropdown>

PROPS

Tooltip <ui-tooltip>

hover/focus 모두 동작 — 키보드 사용자도 도움말을 볼 수 있습니다.

위 아래 오른쪽 
<ui-tooltip content="도움말" position="top">
  <ui-button size="sm">대상</ui-button>
</ui-tooltip>

Tabs <ui-tabs>

활성 탭은 컨테이너의 value가 결정합니다. ui-tab/ui-tab-panel도 같은 value로 연결.

계정 프로필 설정 영역 보안 옵션(2단계 인증 등) 설정 영역 알림 수신 정책 설정 영역 
<ui-tabs value="tab2">
  <div slot="tabs"><ui-tab value="tab1">…</ui-tab></div>
  <ui-tab-panel value="tab1">…</ui-tab-panel>
</ui-tabs>

PROPS

Accordion <ui-accordion>

multiple로 다중 열림 허용. 각 항목은 ui-accordion-item.

pnpm 설치 후 core 패키지를 import하면 전 컴포넌트와 토큰 정의가 함께 적용됩니다. 토큰 CSS 변수를 덮어쓰면 모든 컴포넌트에 반영됩니다. disabled 항목은 열 수 없습니다. 
<ui-accordion>
  <ui-accordion-item open title="설치 방법">…</ui-accordion-item>
  <ui-accordion-item title="테마">…</ui-accordion-item>
</ui-accordion>

total/page-size로 페이지 수 계산, 현재 페이지에 primary 강조.

Navbar <ui-navbar>

브랜드 + 링크 + 액션 슬롯. 이 페이지 상단에 실제로 사용 중입니다. sticky로 고정.

홈 데이터 설정
로그인
 
<ui-navbar brand="My App" sticky>
  <a href="/">홈</a>
  <div slot="actions"><ui-button size="sm">로그인</ui-button></div>

Log <ui-log>

서버 로그·작업 이력 같은 계속 늘어나는 장문 텍스트의 표준 뷰어. role="log" + aria-live 내장, 자동 스크롤(사용자가 위로 읽다가 새 항목이 오면 밀어내지 않음), 오래된 항목 자동 정리, 전체 복사 버튼이 표준입니다. 흔한 <pre> 낙서 대신 이 컴포넌트를 쓰면 레벨 색·타임스탬프·빈 상태가 한결같이 유지됩니다.

<ui-log label="gateway.log" height="240px">
  <ui-log-item level="info" time="19:31:02">GET /healthz — 204 · 3ms</ui-log-item>
  <ui-log-item level="error" time="19:33:12">SSH 점검 실패…</ui-log-item>
</ui-log>

Textarea <ui-textarea>

여러 줄 입력. maxlength를 주면 글자 수가 표시되고, <form>에 참여해 name으로 제출·reset·fieldset disabled가 동작합니다.

<ui-textarea name="memo" rows="4" maxlength="120" placeholder="메모"></ui-textarea>

PROPS

Segmented <ui-segmented>

상호 배타적 선택 그룹(보기 전환·필터). 화살표/Home/End로 이동하면 바로 선택되며 change가 발화됩니다. (role="radiogroup")

목록 격자 지도 선택: list 
<ui-segmented value="list" aria-label="보기 방식">
  <ui-segment value="list">목록</ui-segment>
  <ui-segment value="grid">격자</ui-segment>
</ui-segmented>

PROPS

Stepper <ui-stepper>

current(0부터) 앞은 완료, 현재는 진행 중, 뒤는 대기. 단계에 status="error"를 주면 오류로 표시합니다.

이전 다음 
<ui-stepper current="1">
  <ui-step label="계정" description="이메일 입력"></ui-step>
  <ui-step label="서버"></ui-step>
</ui-stepper>

PROPS

Chip <ui-chip>

라벨·태그. removable이면 × 버튼과 Delete/Backspace로 remove 이벤트를 발화합니다. 칩을 자동으로 지우지는 않으므로 앱이 목록 상태를 갱신하세요.

작업 개인 검토 긴급 읽기 전용 비활성 
<ui-chip variant="primary" removable>작업</ui-chip>
chip.addEventListener('remove', () => { /* 상태에서 제거 */ });

PROPS

Empty State <ui-empty-state>

빈 목록·검색 결과 없음·오류 안내. 기본 슬롯에 다음 행동 버튼, slot="icon"에 아이콘을 넣습니다. 검색 4상태 패턴(7.1)의 "빈 결과"에 사용하세요.

🔍 검색어 지우기 
<ui-empty-state heading="결과가 없습니다" description="다른 검색어로 다시 시도">
  <span slot="icon">🔍</span>
  <ui-button>검색어 지우기</ui-button>
</ui-empty-state>
