# @cubit-ui/core

Cubit UI core: 25 framework-agnostic Web Components (Custom Elements + Shadow DOM). Load the token CSS from `@cubit-ui/tokens` as well.

> **Language notice:** The Korean README ([README.md](https://github.com/tsuel-dev/Cubit/blob/main/README.md)) in the repository root always takes precedence. If this document differs from it or is inaccurate, the Korean README prevails.

## Install

```bash
npm install @cubit-ui/core
```

## Usage

```ts
import '@cubit-ui/core';
```

```html
<ui-button variant="primary">Save</ui-button>
<ui-input placeholder="Name"></ui-input>
```
