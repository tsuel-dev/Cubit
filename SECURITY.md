# Security Policy / 보안 정책

보안 취약점은 공개 이슈로 올리지 말고 **github@mataku.org** 로 알려 주세요.
Please do not report security vulnerabilities in public issues; email **github@mataku.org** instead.

법적 요청, 라이선스·저작권 문의 등 그 밖의 연락도 같은 주소로 받습니다.
The same address is used for legal, licensing and other contact requests.
